# A4 — Results and Outputs

This folder stores outputs from our micro-depot placement experiments.

## Expected Deliverables

- `depots.csv` — recommended depot locations with latitude and longitude.
- `plots/` — maps, clustering visualisations, and evaluation graphs.

## Output Format

The proposed `depots.csv` will contain:

| Column | Description |
| --- | --- |
| `lat` | Recommended depot latitude in decimal degrees |
| `lng` | Recommended depot longitude in decimal degrees |

The final output schema will be confirmed against the A1 Route Planner integration requirements.
